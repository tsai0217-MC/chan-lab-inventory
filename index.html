Quick Guide

How to Use This Inventory System

Please update inventory when material is taken for use so the system reflects what is actually available to the lab.

🧴 Common Buffers

Unopened bottles only

This system tracks unopened buffer bottles only. Whenever a new bottle is taken for use, update the corresponding lot using the arrow controls and submit the change. Bottles that are already open and in use are not included in the inventory count.

🧬 Biological Matrices

Update when material is used

Matrix inventory represents material currently available for use. Whenever matrix material is taken or used, please update the corresponding quantity so the inventory remains accurate.

✓ Keep Inventory Accurate

Update the system at the time material is taken whenever possible. Use Advanced Update for adding new reagents or matrices, receiving stock, recording expired or discarded material, performing physical counts, or correcting known inventory errors.

    ▸ Buffer Tracking System — Guidelines & Instructions

    What This System Tracks

    This system tracks unopened bottles only. Each reagent may contain multiple lots, each with its own lot number, expiration date, and unopened bottle count.

    Opening a Buffer

    Expand the reagent, identify the exact physical lot, and press ▼ once per bottle opened. The change remains pending until Submit Changes is pressed. Use ▲ only to undo a pending ▼.

    Storage & Registration

    Material delivered to the 423360 hallway refrigerator is not automatically registered inventory. Add it as New Stock when transferred into a registered storage location.

    Expiration Status

    Expired = red !, within 14 days = yellow !, more than 14 days = green.
